用法：先发视频，再发 `/upmedia 67` → 分秒帧里出现 `67.mp4`。
命令先到也行：发完机器人等 5 分钟内的下一个视频。

名字可以带扩展名（`/upmedia 67.mp4`），不带就沿用原视频的扩展名。
名字里的非法字符会被替换成 `_`。

```bash
# 看
lark-cli --profile [已脱敏] application +slash-command-list

# 新增
lark-cli --profile [已脱敏] application +slash-command-create \
  --command upmedia --description "把最新一条视频上传到分秒帧，并重命名为你给的名字（例：/upmedia 67）" \
  --description-i18n zh_cn="上传视频到分秒帧并重命名"

# 改说明（命令名不能改）
lark-cli --profile [已脱敏] application +slash-command-update \
  --command upmedia --description "新说明"

# 删（高危，重建会换 command_id）
lark-cli --profile [已脱敏] application +slash-command-delete \
  --command-id 7700916537737120774 --yes
```

要点：

- 命令名不带前导 `/`，同一应用内唯一，上限 100 条。
- **客户端缓存约 5 分钟**，改完不会立刻在聊天框里看到。
- ⚠️ **新增命令必须发版才会出现在候选列表**（2026-10-28 踩到：`/health` 服务端 13:05 就注册好了，客户端 30 分钟后仍不显示）。
  客户端读的是**已发布版本**的命令快照，不是实时接口。建完要去
  https://open.feishu.cn/app/[已脱敏]/version 创建版本并发布；企业自建应用开了审核还要管理员通过。
  应急：直接手打 `/命令名` 发出去也能用——斜杠命令只是填文字，机器人收到的是普通文本。
- 斜杠命令本身只是「把文字填进输入框」，机器人收到的是普通文本消息，靠代码里解析。
- 命令走**应用身份**（新应用有 `application:app_slash_command:read/write`），不用登录个人账号。

### 文本命令（不是注册的斜杠命令，直接发文字）

| 命令 | 作用 |
| --- | --- |
| `/help` | 回一张能力卡片。**陈俊杰本人 → 完整版（`help.md`）；其他同事 / 群聊 → 精简版（`help-lite.md`）。每次现读，改完不用重启**；两份里的 `{{DRIVE_FOLDER_URL}}`、`{{TARGET_LABEL}}` 发送时替换成当前云盘链接和分秒帧目标名 |
| `/target` | 看当前上传目标；`/target <分秒帧链接>` 直接换（支持 `?path=` 文件夹），写进 config.json，下一条视频生效 |
| `/base 把 70 集的素材生成进展改成已上传` | 改表：集数 + 字段 + 值，值认别名 |
| `/flow` | 立刻跑一次流程巡检（到排期置进行中、发一审卡片） |
| `/flow test 45` | 给某一集发一张一审卡片（测试用） |
| `/flow backfill` | 把当前所有「已粗剪待一审」补发一遍卡片 |
| `/health` | 手动体检，立刻回一张体检卡（跟工作日 10-19 点整点那张一样） |
| `/release` | 私聊预览或恢复未发送草稿，可修改标题和正文，点击发送按钮才发群 |
| `/release status` | 版本公告现状：线上版本 / 已记录版本 / 待发布改动几条 / 公告发到哪个群 |
| `/release now` | 重新生成当前版本预览（补发也须点击按钮确认） |
| `/公告群 逆天萌兽制作组` | 指定版本公告发到哪个群；不带名字就列出机器人在的所有群。**注册不了斜杠命令**（飞书命令名只允许 `^[a-z][a-z0-9_-]{0,31}$`，中文不行），只能手打 |
| `/release` | 已注册成斜杠命令；手打同样能用 |
