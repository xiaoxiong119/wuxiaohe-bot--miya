# 乌小河本机管理台

双击 `06-运维/打开机器人管理台.command`，或者访问 http://127.0.0.1:18765/ 。关闭网页不会关闭管理台。重启电脑后再次双击启动。只监听本机，不向局域网或公网开放。

## 已接入的功能

- 通知人员：从排期映射、现有免通知名单和手动添加人员合并显示；读取和写入真实 config.json 的 privateNotificationOptOut，沿用机器人已有统一消息出口。修改立即生效；允许通知不会主动发送消息。仅针对以 open_id 发送的私聊消息/卡片，不阻止群通知、群内 @、会话回复。列表不是完整通讯录。
- 功能链接：九项可编辑链接。按每项提示显示生效时间；表格链接同步更新 appToken/tableId/viewId，云盘更新 folderToken，排期来源更新 spreadsheetToken/sheetId。Wiki 解析使用机器人既有凭证，只读查询，不外发通知。新表必须具备业务所需字段。不会重置批注同步水位，切换到新项目后的首次同步范围需在飞书命令中选择。
- 运行概览：核对 PID 对应的命令确为此工程 index.js，显示运行时长、日志更新时间和北京时间当日已有自检报告。进程状态不代表全部业务链路可用。完整业务体检沿用飞书 /health。
- 日志：bot.log、bsk.log、restart.log、admin-audit.jsonl；读取末尾 256 KB，筛选后最多 600 行，支持搜索、错误筛选、每五秒刷新和下载当前结果。常见凭证字段做基本脱敏，下载仍可能包含业务信息。
- 保存保护：允许修改的字段白名单、配置版本冲突校验、原子写入、每次保存前自动备份、最近三十次修改记录。快照位于 backups/admin，历史记录位于 logs/admin-audit.jsonl。已提供备份选择和恢复界面，见升级说明。

界面不读取 .env 内容，不提供任意文件或命令执行接口。状态/日志/修改接口要求随机会话令牌，并检查 Host 与 Origin。升级已接入机器人通知出口和运行状态，业务流转规则保持原样。

## 开发与验证

启动：`~/.workbuddy/binaries/node/versions/22.22.2-6/bin/node admin/server.js`

离线测试：同一 Node 执行 `admin/test.js`（端口 18766）。测试在系统临时目录写配置，不修改真实配置，不发送飞书消息。覆盖通知双向开关、旧配置冲突、非法链接和字段拒绝、无关字段保留、备份、鉴权、跨站请求拦截、日志路径限制。

`ADMIN_PORT` 可覆盖端口；双击入口固定默认端口。`ADMIN_TEST_ROOT` 仅供隔离测试，不应在实际启动时设置。

## 2026-10-29 管理台升级

- 人员名单增加正式任务表制作师、审片人、剪辑师读取，当前核实10位，包括韦成艳、屠斯航。新增“同步公司通讯录”，按部门分页读取全员、按 open_id 去重，保留多部门归属；读取失败不会标记完整，也不删除已缓存人员。
- 当前应用缺少组织通讯录权限，全公司名单及真实部门仍未取得；用户已选择先完成可做部分，保留待同步提示。当前10位显示在“部门待同步”。开通后在人员页点击同步即可。
- 六类私聊通知许可：一审、修改与素材、精剪、终审、体检、上传与系统回执。通过发送出口校验；功能指定名单仅限制原业务收件人，不自动新增业务通知对象，不改变群聊和会话回复。全局免通知优先。
- 免打扰采用 Asia/Shanghai，支持跨午夜；期间跳过、不补发，同起止为全天。原有流程去重仍然有效，重新开启不会自动重发历史卡片。
- 上传队列实时快照和批注/排期同步忙碌状态。机器人每两秒落盘，超过12秒视为过期；显示当前进程匹配快照。
- 失败重试仅支持本地 failed 视频恢复和升级后记录的飞书消息上传失败（12小时内）。云盘失败、历史未记录失败、同步失败需沿用原命令人工重试，不提供无条件自动重放。
- 登录过期提醒来自上传真实报错，后续成功上传清除提示；浏览器服务检测不证明登录有效，不自动发飞书告警。
- 空闲时起停机器人；配置回退保留回退前快照；downloads 和 inbox/done 直接文件的统计及超过7天文件可恢复归档。归档不释放空间，不永久删除，不操作任务临时目录。

- 新增离线验证：admin/test-upgrade.js，覆盖通知出口规则、免打扰边界、配置回退、失败恢复与重复请求拒绝、通讯录分页。既有排期、批注同步、公告与免通知回归测试通过。
