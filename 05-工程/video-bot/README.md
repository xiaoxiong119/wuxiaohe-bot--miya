## 架构

```
飞书云端
  │  长连接（WebSocket，不需要公网 IP / 域名 / 内网穿透）
  ▼
src/index.js        主进程：收事件 → 3 秒内返回 → 入队
  │
  ├─ 下载视频      im.v1.messageResource.get
  │
  ▼
src/worker.js       子进程：bsk 驱动 Chrome → 分秒帧网页上传
  │                 （必须独立进程，主进程里同步调用会堵死长连接心跳）
  ▼
回消息              im.v1.message.create
```

## 一次性准备（约 5 分钟）

### 1. 建应用

打开 https://open.feishu.cn/app → 「创建企业自建应用」，名字随便（建议「视频转存助手」）。

创建后到 **凭证与基础信息** 页，抄下 `App ID` 和 `App Secret`。

### 2. 开机器人能力

左侧 **添加应用能力** → 开启「机器人」。

### 3. 开权限（只要这 3 个）

左侧 **权限管理**，搜索并开通：

| 权限 | 用途 |
| --- | --- |
| 读取用户发给机器人的单聊消息 `im:message.p2p_msg:readonly` | 收私聊消息 |
| 获取消息中的资源文件 `im:resource` | 下载视频 |
| 以应用身份发消息 `im:message:send_as_bot` | 回执 |

> 如果以后想让机器人在群里收视频，再加 `获取群组中所有消息 im:message.group_msg`，并把群 id 填进 `config.json` 的 `allowGroups`。

### 4. 事件订阅改成「长连接」

左侧 **事件与回调** → **事件配置** → 订阅方式选 **「使用长连接接收事件」**（不要选 webhook，就不用公网地址）。

然后 **添加事件** → 搜索 `接收消息` → 勾选 `im.message.receive_v1`。

### 5. 发版

左侧 **版本管理与发布** → 创建版本 → 申请发布。
企业自建应用需要管理员审核，你自己是管理员就自己批一下。

## 用法

私聊（群里需先把群号填进 `config.json` 的 `allowGroups`）：

1. 发一个视频 → 机器人回「收到 xxx.mp4。要传的话发：/upmedia 名字」
2. 发 `/upmedia 67` → 机器人回「好，把 xxx.mp4 传成「67.mp4」，开始。」
3. 传完回「✅ 已上传分秒帧：67.mp4，列表 N → N+1 项」+ 项目链接

也可以命令先到：发完 `/upmedia 67` 再发视频，机器人等 5 分钟内的下一条。

细节：

- 名字不带扩展名就沿用原视频的（`.mp4`）；带了就按你给的。
- 非法字符（`/ \ : * ? " < > |`）会被替换成 `_`。
- 连发多个视频会按到达顺序排队，`/upmedia` 每次取最早那条未处理的。
- 同一条消息重复推送会自动去重（长连接超时会重推，靠 `state.json` 里记的 `message_id` 挡掉）。

## 改配置 `config.json`

```json
{
  "projectUrl": "https://app.mediatrack.cn/projects/<项目id>/files",
  "allowP2P": true,
  "allowGroups": ["oc_xxx"],
  "allowedExtensions": [".mp4", ".mov", ".m4v", ".mkv", ".avi", ".flv", ".webm", ".ts"],
  "replyOnReceive": true
}
```

换分秒帧项目只改 `projectUrl` 里的项目 id。

## 已知限制（都是硬的，绕不过）

| 限制 | 说明 |
| --- | --- |
| **电脑要开着** | 分秒帧没有上传 API，只能靠本机 Chrome 的登录态驱动网页。机器休眠/关机 = 机器人不干活 |
| **单文件 ≤ 100 MB** | 飞书 `messageResource.get` 接口的硬限制。更大的文件得先在飞书端压缩或分卷 |
| **分秒帧要登录着** | Chrome 里分秒帧登录态过期就传不了，报错会让你重新扫码 |
| **Chrome 扩展要开「允许访问文件网址」** | 否则注入文件会报 `Not allowed`，在 `chrome://extensions` 里开 |
| **同名文件不覆盖** | 分秒帧平台行为，会并存两份 |
| **依赖页面结构** | 分秒帧网页改版要重新对选择器（在 `src/mediatrack.js`） |

## 排错

| 现象 | 原因 |
| --- | --- |
| 日志无 `长连接已建立` | 事件订阅方式没切成「长连接」，或应用版本没发布 |
| 发视频没反应 | 机器人不在私聊里 / 应用可用范围不含你 / 没开机器人能力 |
| `凭证无效 code=10014` | App Secret 填错 |
| 上传报「登录已过期」 | 去 Chrome 打开分秒帧扫码重登 |
| 报「没找到上传按钮」 | 分秒帧页面改版，或登录态异常 |
