## 建议优先回收

| scope | 风险 | 乌小河用不用 |
| --- | --- | --- |
| `im:message:send_multi_users` | 批量群发，可对多人推送 | 不用 |
| `im:chat.members:write_only` | 增删群成员 | 不用 |
| `im:chat.managers:write_only` | 增删群管理员 | 不用 |
| `base:record:delete` | 删多维表格记录 | 不用 |
| `base:table:delete` | 删数据表 | 不用 |
| `sheets:spreadsheet:write_only` | 改电子表格内容 | 只读就够 |
| `contact:contact.base:readonly` | 读通讯录 | 代码里从没调用 |
| `mail:*`（15 项） | 读写邮箱 | 不用 |
| `calendar:*`（12 项） | 日历读写 | 不用 |
| `okr:*`（11 项） | OKR 读写 | 不用 |
| `approval:*`（5 项） | 审批 | 不用 |

邮箱 + 日历 + OKR + 审批 + 考勤 ≈ 60 项，是最容易摘掉、也最能拿来说服管理层的一块。关完要重新发版才生效。

## 怎么复核

```bash
export PATH="$HOME/.local/bin:$PATH"
lark-cli api GET "/open-apis/application/v6/applications/[已脱敏]" \
  --as bot --params '{"lang":"zh_cn"}' \
  | jq '[.data.app.scopes[].scope]' > 03-权限/scopes-live.json
jq 'length' 03-权限/scopes-live.json
```

`--as bot` 是必须的，用 user 身份会报 `99991668`。
