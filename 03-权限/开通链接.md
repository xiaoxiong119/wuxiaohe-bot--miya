# 一键开通权限链接

_应用：`[已脱敏]`（乌小熊的飞书 CLI）。点开 → 全选 → 申请。_

**规矩**：以后要开新权限，直接给链接，不让你自己去后台搜。

**踩过的坑**：`im:resource` 只是「允许碰附件」，真正下载某条消息里的视频，飞书还要求 `im:message:readonly`（获取单聊、群组消息）。少了它，下载接口报 `400 / 99991672`，机器人会回「处理失败：下载失败」。下面的链接已经包含这条。

生成方式（要临时加权限时）：

```bash
cd ~/WorkBuddy/乌小河机器人/06-运维
./scope-link.sh im:message:send_as_bot im:resource     # 传 scope
./scope-link.sh --set 功能1                            # 用预置组
```

换应用：`APP_ID=cli_xxx ./scope-link.sh --set 功能1`

**当前缺的就一条**（读记录要用）：

```
https://open.feishu.cn/page/scope-apply?clientID=[已脱敏]&scopes=base%3Arecord%3Aretrieve
```

坑：`base:record:read` 名字像「读记录」，实际只覆盖检索接口；列记录 / 按条件查记录要 `base:record:retrieve`（或 `bitable:app:readonly`）。写记录用 `base:record:update`，这条已经有。

## 云盘文件夹列表（读文件夹里有什么）

```
https://open.feishu.cn/page/scope-apply?clientID=[已脱敏]&scopes=space%3Adocument%3Aretrieve
```

`space:document:retrieve`＝获取云空间文件夹下的云文档清单。比 `drive:drive:readonly` 窄，优先用它。
下载文件本身用 `drive:file:download`（已有），但**文件要分享给应用**否则 403。
