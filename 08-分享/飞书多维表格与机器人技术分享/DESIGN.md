# DESIGN.md · 飞书多维表格与机器人技术分享

## 一、需求对齐

| 维度 | 结论 |
| --- | --- |
| 主题 | 飞书多维表格 + 机器人怎么配合：乌小河这条链路的机制、插件写法、回写方案与踩坑 |
| 目标 | 让同事听完能自己用（发命令、配自动化），让技术同学知道三层怎么搭、坑在哪 |
| 受众 | 影视资产管理/制片团队 + 少量技术同学（同一场） |
| 场合 | 公司内部技术分享会，投影 + 飞书共享 |
| 调性 | 克制、工程感、讲事实和代价，不讲愿景 |
| 页数 | 18 页（20 分钟，约 1 分钟/页） |

## 二、全局视觉约定

### ① 画布与安全区
- 1280×720；padding 上下 60 / 左右 60；内容区 1160×600
- 页脚：`乌小河 · 技术分享` 左、`NN / 18` 右，y = 670，14px；封面 / 目录 / 章节页 / 封底不出现页脚

### ② 配色（科技蓝）

| 槽位 | Hex | 用途 |
| --- | --- | --- |
| 主色 | `#1D4ED8` | 编号、色块、关键结构、连线 |
| 主色浅 | `#EFF6FF` | 浅底卡片 / 浅色分区 |
| 辅色 | `#3B82F6` | 图表第二序列、次级标签 |
| 强调 | `#F97316` | 全篇唯一高饱和色，只点关键结论 / 断点 |
| 墨色 | `#0B1F3A` | 深色强调卡底、主标题 |
| 正文 | `#475569` | 正文 |
| 弱化 | `#94A3B8` | 眉标、页脚、辅助文字 |
| 线 | `#E2E8F0` | 1px 分区线 |

面积纪律：主色 ≤60%，辅色 ≤30%，强调色 ≤10%；深色大块每页 ≤1；禁用阴影。

### ③ 字体
- 中文 / 西文：`Microsoft YaHei`（单一字族，全篇不换）
- 代码：`Consolas`
- 阶梯：封面主标 72 / 章节大字 60 / 巨型数字 104 / 页面主标 34 / 卡片小标 24 / 正文 18 / 注释 14

### ④ 视觉母题
- 内容页固定骨架：左上 14px 眉标（`01 · 问题`）→ 34px 主标题 → y≈142 处 1px 贯通细线 → 正文区
- 章节页固定：左侧 104px 大编号 + 竖排章节名 + 一条竖细线，右侧一段 ≤50 字概述
- 结构图一律用 Box 边线 + FAIcon 箭头搭建，不用位图

### ⑤ 配图清单
全篇无摄影素材，由结构图（流程链 / 分层 / 对比 / 矩阵）承担视觉。不用 ImageGen 生图，避免与工程语气冲突。
