# 给乌小河传视频 · 操作教程

_适用：所有需要把粗剪/素材交给后期的同事。更新于 2026-10-27。_

## 先说清楚它是什么

乌小河是飞书里的一个机器人，你把视频交给它，它自动传到 **分秒帧** 的指定项目里，并在飞书回你一条结果。

- 传的是**分秒帧**，不是网盘、不是微信群文件
- 目标项目由小熊统一配置（当前是《逆天萌兽2》的「粗剪」文件夹）
- 它跑在小熊电脑上，**小熊关机它就停**，急件请提前说

---

## 按文件大小，选一条路

| 文件大小 | 怎么给 | 一句话 |
| --- | --- | --- |
| **≤ 100 MB** | 飞书私聊直接把视频发给乌小河 | 发完再发 `/upmedia 名字` |
| **> 100 MB** | 传到「云盘收件夹」，再发命令 | `/driveup 文件名` 或 `/drive` 批量 |

100 MB 是飞书消息接口的硬限制，不是机器人挑食——超过的视频它**根本下载不下来**，会直接告诉你走第二条路。

---

## 方式一：≤ 100 MB，聊天框直发

1. 打开与 **乌小河** 的私聊
2. 把视频文件发过去（当作文件/视频都行，不要压缩包）
3. 它回你：「收到 xxx.mp4。要传的话发：/upmedia 名字」
4. 你发：`/upmedia 71`
5. 它回：「好，把 xxx.mp4 传成「71.mp4」，开始。」
6. 传完回你：

```
✅ 已上传分秒帧：71.mp4
列表 116 → 117 项
https://app.mediatrack.cn/projects/...
```

**名字规则**

- `名字` 就是分秒帧里显示的文件名，`/upmedia 71` → `71.mp4`
- 不带扩展名就沿用原视频的；带就按你给的（`/upmedia 71.mov`）
- 可以中文：`/upmedia 71-殷念特写`
- 同名不会覆盖，分秒帧里会并存两份——传之前确认一下名字

**命令可以先发**

先发 `/upmedia 71` 再发视频也行，机器人会等你 5 分钟内的下一个视频。

**只能在私聊里用**

群里发它不接（避免刷屏和误传），要传就开跟乌小河的私聊。

## 方式二：> 100 MB，走云盘收件夹

**收件夹地址**（收藏一下）：

```
https://icnbott7dtg3.feishu.cn/drive/folder/[已脱敏]
```

1. 打开上面的链接 → 点「上传」→ 选你的视频
2. 等上传完成（云盘页面显示 100%）
3. 回到与乌小河的私聊，发：

```
/driveup 71
```

4. 它先在文件夹里找名字，找到就下载、上传，回执同上

**名字写不全也行**

`/driveup 71` 能匹配 `71.mov`、`71-修改.mp4`；匹配到多个它会列出来让你写具体点；一个都没匹配到，它会把文件夹里现有的文件列给你看。

**一次传好几个**

先把文件都传进收件夹，然后发：

```
/drive
```

它会把收件夹里**所有还没传过**的视频一次性传掉，回你「文件夹里 N 个、新视频 M 个」。

---

## 传完会发生什么

1. 文件出现在分秒帧对应项目的「粗剪」文件夹里
2. 飞书收到回执：文件名 + 列表数变化（`116 → 117`）+ 项目链接
3. 列表数没变但回执是 ✅，多半是同名文件进了子目录，点链接确认一下
4. 传失败会明确告诉你原因（登录过期、权限、文件太大、网络）

## 常见问题

**发了视频没反应？**
先看文件大小。超过 100 MB 用云盘那条路。其余情况找小熊看机器人是不是没开。

**`/driveup` 说「没匹配到」？**
把文件名发短一点，比如 `71` 而不是 `71-殷念特写-改.mov`。它会列出文件夹里现有的名字。

**在群里 @ 它能用吗？**
不能，现在只开私聊。群里发的东西它不会处理。

**能一次发多个视频给聊天框吗？**
可以，按顺序排队传。但每个都要单独发一次 `/upmedia 名字`。

**传重了怎么办？**
分秒帧不覆盖，会并存。找小熊在分秒帧里删掉多出来的那条。

**能传到别的项目吗？**
不能，目标由小熊统一配。要换项目找他说，用 `/target` 一条命令就切了。

**会占我流量/要装东西吗？**
不用装任何东西，全程在飞书里发消息。下载和上传都在小熊电脑上跑。
