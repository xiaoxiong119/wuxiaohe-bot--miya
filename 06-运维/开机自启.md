# 开机自启（launchd LaunchAgent）

2026-10-30 装好。机器人开机/登录后自己起来，不用再手动跑 `start.sh`。

## 装了什么

| 文件 | 作用 |
|---|---|
| `~/Library/LaunchAgents/com.wuxiaohe.videobot.plist` | 自启任务定义（Label `com.wuxiaohe.videobot`） |
| `~/video-bot` → `05-工程/video-bot` | 软链，给 launchd 一个纯英文入口（plist 里不写中文路径） |
| `05-工程/video-bot/launchd-run.sh` | launchd 真正调起的脚本：补齐环境 → 确保 bsk 在跑 → `exec node src/index.js` |

`launchd-run.sh` 和 `start.sh` 的区别：`start.sh` 把主进程甩脱、自己退出（给人手动用）；`launchd-run.sh` 用 `exec` 让 node 顶替自己，launchd 才知道"主进程是谁"，崩了才能自动拉。

## 什么时候生效

- **重启 / 注销再登录** → 自动生效，无需任何操作。
- **想现在就生效**（不重启）：终端里跑 `~/video-bot/start.sh`（它会检测到已装自启并 `launchctl bootstrap`），或直接
  `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.wuxiaohe.videobot.plist`
- 验证：`launchctl print gui/$(id -u)/com.wuxiaohe.videobot | head -6`，看到 `state = running` 即成功。

> 注意：LaunchAgent 是**用户登录后**才跑。重启后如果停在登录界面没人登录，机器人不会起（要开机即跑得用 LaunchDaemon，但那种没有 GUI 会话，bsk 驱动不了 Chrome，分秒帧上传用不了，所以选前者）。

## 日常操作没变

```bash
cd ~/video-bot
./start.sh      # 起（已装自启时会交给 launchd，避免出现两个实例）
./stop.sh       # 停（会先 launchctl bootout，否则 KeepAlive 会立刻拉回来）
./restart.sh    # 重启（已加载时走 launchctl kickstart -k）
```

体检 `06-运维/status.sh` 里多了一行「开机自启」状态。

## 永久取消自启

```bash
launchctl bootout gui/$(id -u)/com.wuxiaohe.videobot
mv ~/Library/LaunchAgents/com.wuxiaohe.videobot.plist ~/.Trash/
```

（只做 `bootout` 是临时停：下次登录还会起来。）

## 设计上的几个决定

- **KeepAlive 用 `SuccessfulExit=false`**：崩了才重拉；正常退出（比如发现已有实例、主动让位）不重拉，避免和手动实例死循环。
- **让位逻辑**：`launchd-run.sh` 启动前先看 `.bot.lock`，持锁进程还活着就 `exit 0` 退出。所以手动跑的实例不会被 launchd 抢事件，也不会出现一秒一崩的重启风暴。
- **`AbandonProcessGroup`**：停任务时不连带杀 bsk，bsk 是独立守护进程。
- **环境自己补**：launchd 只给 `PATH=/usr/bin:/bin:/usr/sbin:/sbin`，脚本里重新拼 PATH、清代理、清 `NODE_OPTIONS`、找 Node ≥22（先 PATH，再退回 WorkBuddy 托管目录）。同一份脚本在新 Mac 上也能用。

## 坑

- **`launchctl bootstrap` 在 WorkBuddy 会话里必定报 `Bootstrap failed: 5: Input/output error`**，连 `/bin/echo` 的最小 plist 也一样，`user/501` 域同样。不是 plist 写错、也不是中文路径。要在真实终端里执行才行；或者干脆靠登录时自动加载。
- plist 里的 `StandardOutPath` 指到 `logs/bot.log`，和手动启动共用一份日志。
- 自启生效后，`kill` 掉机器人 10~20 秒会被拉回来。要真停必须 `./stop.sh`（它走 bootout）。
